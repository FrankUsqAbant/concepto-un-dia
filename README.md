# Concepto "Un día"

Segundo diseño del portafolio de Frank Abanto: un cielo en WebGL que cambia del amanecer a la noche.
Sitio estático de un solo archivo (`index.html`).

- Arrastra el sol (o usa el control accesible) para cambiar el momento del día; el cursor actúa de viento sobre las nubes.
- El workflow `Capturas y mediciones` prueba la página en GitHub Actions y deja capturas e informe como artefacto.
